# 首轮验证记录

日期：2026-10-30（北京时间）。版本：0.1.0，方法 `ap-dvdt-1`。

## 测试环境与结果

macOS 14.3.1，Apple M1 Pro 上的 x86_64 Python 3.12.4（Rosetta 进程）。PySide6-Essentials 6.9.3、pyqtgraph 0.13.7；完整依赖快照见根目录锁文件。

- 37 项 pytest 测试通过，包含分析、读写、错误处理和无窗口 Qt 集成测试。
- Ruff 检查与格式检查通过，pip 依赖一致性检查通过。
- 已知三角波幅度约 100 mV、半峰宽约 1 ms、最大斜率约 ±100 mV/ms、AHP 相对基线 10 mV 与定义一致。
- 另以 10 / 20 / 50 kHz 合成同一波形，均识别 3 次事件，半峰宽 1 ms。
- 演示记录分别 3 次、5 次事件，脚本端到端导出结果符合预期。
- 生成 ABF1 二进制再读入，验证两个 sweep 的采样时间、电压缩放和事件数；pA 通道明确拒绝分析。
- Qt 测试使用 `QT_QPA_PLATFORM=offscreen`，覆盖分析、剔除/恢复、切换、参数失效、后台失败恢复、回调主线程约束和后台导出。未做屏幕视觉或人工鼠标交互检查。

## 公开 ABF2 兼容性样本

来源：[pyABF 官方测试数据](https://github.com/swharden/pyABF/tree/main/data/abfs)。仅下载到本地临时验证目录，没有打入仓库或应用。

- `17o05027_ic_ramp.abf`：ABF 2.6.0.0，mV，20 kHz，2 sweeps，默认全段检测数 6、9。
- `17o05028_ic_steps.abf`：ABF 2.6.0.0，mV，20 kHz，16 sweeps，默认全段检测数 10、11、12、12、12、16、18、20、22、25、29、32、35、39、40、42。

这些事件数仅为程序运行输出，缺少人工标注真值，不用于证明真实实验中的灵敏度、特异度或与 Clampfit 完全一致。

## 应用兼容性

本地应用按当前 Python 进程打包为 x86_64，可在此机器通过 Rosetta 运行，Intel Mac 需满足依赖要求。当前依赖使本地包最低以 macOS 14 为目标；只实测 14.3.1，不承诺所有更老版本可用。Apple Silicon 原生版本由 macOS ARM 构建环境另行打包；GitHub 工作流按实际 runner 架构产出应用。

应用包含依赖，用户无需安装 Python。未使用 Apple Developer ID 签名和公证，只有打包工具的本地签名。Mac 可能要求明确允许打开。

## 证据边界

没有用户自己的 ABF 样本，尚未做实验协议适配、与人工标注逐事件比较、液接电位修正或与 Clampfit 输出对照。没有自动读取刺激电流和刺激时序。正式统计前应在代表性实验 sweep 上复核事件与阈值，并选择统一的参数和质量控制规则。

GitHub CI 状态以该仓库 Actions 页面实时结果为准，本记录不把本地通过等同于远端 CI 通过。
