# 全部动作电位参数的方法核实

[完整逐字段审查与引用（English）](method-review.md) · [现行测量定义](measurement-definitions.md)

核实日期：2026-11-02。已检查现有全部动作电位测量、sweep 描述汇总、各指标均值/有效数和质量计数。依据包括 Gouwens 2019 全文 Methods、固定 commit 的 IPFX/eFEL 源码与官方定义、Lazic 2010 的伪重复讨论，以及 Kapoor & Narayanan 2023 的机器学习信息泄漏研究。引用、具体函数/feature 和源码哈希见英文逐字段文档及 `method-review-sources.json`。

本次完成的是文献和代码方法审查；尚未用你的实验数据与人工或 Clampfit 逐事件验证。保留数值方法 `ap-dvdt-1`，新增独立版本为 `1` 的方法注册表，避免合法的方法差异导致旧结果无法复现。

## 波形测量的结论

- **峰值时间、电位和事件数**：峰值取采样点，不做拟合。候选峰满足最低电位、突出度和距离要求；分析边界端点不计峰。它不是 Allen/IPFX 的完整检测流程，小幅放电和刺激伪迹仍需复核。
- **阈值时间/电位**：目前从最大上升斜率之前寻找最后一次固定 dV/dt 向上穿越，默认 20 mV/ms，线性插值。Gouwens 2019 和 IPFX 还使用平均最大上升斜率的 5% 细化起点。因此相同的“20”不能证明阈值算法相同。
- **幅度**：峰值减阈值，与 eFEL 的 onset-to-peak 定义属于同一家族；起点算法不同仍会产生差值。不是峰值减静息电位。
- **半峰宽**：在阈值与峰值之间的半幅电位测量，交点插值。与 eFEL 的起点参考属于同一家族；IPFX 的 `find_widths` 先使用 trough-to-peak 半高，低于阈值时回退到阈值参考。不能直接宣称不同软件同名数值等价。
- **上升时间**：阈值到峰值的时间，不是 10%–90% 上升时间。
- **最大上升/下降速率**：使用电压时间梯度，上升段从阈值到峰，下降段从峰到 AHP 窗最低点；下降保留负号。滤波、采样率和分段边界影响极值。
- **AHP 最低点时间、电位与两种深度**：默认峰后 20 ms 内搜索，在下一保留事件起点或分析结束前截断。不能直接称为独立的快/中/慢 AHP 成分。深度分别为阈值减最低点、基线减最低点，低于参考值时为正。eFEL `AHP_depth` 用最低点减基线，符号相反；窗口和基线也需对齐。
- **基线**：原始电压在指定半开区间内的中位数；不自动等同于静息膜电位。未指定时会使用自动选择的区间并警告，实际区间写入汇总。

## 放电统计的结论

- **发放率**：保留峰数除以完整分析时长；无事件为 0。eFEL `mean_frequency` 的分母截至最后峰，可能与当前方法不同。瞬时频率均值也不等于全窗发放率。
- **首峰潜伏期**：首峰相对于分析起点；没有自动识别刺激开始。IPFX latency 使用阈值时间。需要区分刺激到阈值与刺激到峰值。
- **ISI 与瞬时频率**：相邻保留峰之间的时间差及其倒数；IPFX 的相关统计使用阈值时间。排除事件后会重新计算。
- **平均 ISI 与 ISI CV**：使用全部 ISI，CV 为样本标准差（ddof=1）除以均值，至少 3 个峰。eFEL `ISI_CV` 默认排除首个 ISI，除非显式设置 `ignore_first_ISI=0`。
- **末/首 ISI 比**：末 ISI 除以首 ISI，至少 3 个峰。它不同于 IPFX/eFEL 的相邻 ISI 归一化差平均值。例如 ISI 为 20、40 ms，当前比值为 2，而 IPFX 归一化差为 1/3；不能把两者都含糊称作同一种适应指数。
- **七项波形指标的均值和有效数**：阈值、幅度、半峰宽、最大上升/下降斜率、两种 AHP 深度均在 sweep 内按非缺失值算术平均，并给出有效事件数。有效数不是独立细胞/动物数；质量标记不会自动剔除。
- **质量计数**：标记事件数表示至少带一个质量提示的保留事件数量；多个标记不会重复计一个事件。缺失值为 null/空白，不能补零。

同细胞多个动作电位、多个 sweep，以及同动物多个细胞通常相关。组间推断需根据处理分配单位、配对/重复结构和协议确定聚合或层级模型，同时报告各级数量、效应量、不确定性和多重比较处理。项目目前仍只自动输出逐事件/逐 sweep 描述统计，不自动作细胞/动物/组级显著性检验。

## 已落实的改进

`analysis.json` 新增 `method_manifest`：全部指标的单位、公式、比较说明、引用及审查状态；同时保存 `analysis_code_sha256`，标识实际分析内核文件。每条分析已有的 config、实际基线/分析区间、平滑点数、排除项和警告继续保存。单模块哈希不能代替完整环境记录；代理仍需保存 Git commit、影响计算的修改和执行脚本。

这次没有修改默认阈值、窗口、半峰宽参考或统计公式。未来确需兼容某文献/软件时，应显式新增可选方法并做数值对照；发现真实错误时应修复、升级数值方法版本并说明历史结果影响。

## 机器学习建议

当前不建议把训练模型接入参数测量主路径。已有明确公式的指标先做好定义、验证和追溯；目前没有实验室标注集和独立测试集，无法证明机器学习优于现有规则。最初方法审查未引入 ML；后续真实数据复核增加了可选的试验性 Isolation Forest 排序，见 [机器学习复核说明](ml-review.md)。尚无监督检测/测量模型，也没有准确率提升结果。

优先考虑的后续能力是**辅助质量筛查与复核排序**：识别疑似刺激伪迹、削顶和潜在漏检，输出待复核候选。要提升漏检召回，模型还需检查当前检测器未选中的片段。只有在匹配协议、足够独立细胞和外部验证下，才考虑按参数探索表型聚类；聚类本身不能证明细胞类型。细胞外 spike sorting 的结论不能直接移植到这里的细胞内电流钳记录。

引入前需要人工标注与分歧复核，按动物/独立来源分开训练、验证、测试，同细胞或相邻片段不能跨集合。先比较规则基线和轻量分类器；事先定义事件匹配容差，报告 precision/recall、每分钟误检、参数误差/偏差、有效率和人工复核时间，并检查跨日期/设备表现。去噪尤其要检查宽度、阈值和斜率失真。模型应先影子运行、允许拒判/关闭，保留原始信号与确定性计算路径。具体计划和研究依据见英文文档。

## 使用方式

你仍然提供 ABF 和目标即可，例如：

```text
$software-engineer
请使用 neurospike 分析这些 ABF 的全部现有动作电位参数。
先按已核实的方法检查协议是否适用；采用现有 ap-dvdt-1 并保留方法依据。
如果与我指定论文或 Clampfit 定义不同，明确差异后再计算对应的可选指标。
给我结果表、必要复核图和质量说明，不开发 Qt。
```

若要严格复现特定论文，请提供 DOI/论文路径及相关协议。尚无原始数据时只能完成方法与软件验证，不能给出你的实验结论。
