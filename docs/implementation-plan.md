# 第一版需求与工程设计

用户：不编程的神经科学实验研究者。平台：macOS。主要数据：pCLAMP ABF。范围：电流钳诱发和自发动作电位分析，不包括采集硬件控制。

选择 Python：NumPy/SciPy 提供可独立验证的数值实现，pyABF 负责 ABF 兼容，Qt/PySide6 与 pyqtgraph 提供本地桌面交互。架构采用一个桌面应用与共享计算内核，避免不必要的服务器或数据库。结果用标准 CSV/JSON，便于后续用 Excel、Prism 或 Python 统计。

## 模块职责

1. `models`：有效的均匀采样电压模型，保护原始数组不被后续测量修改。
2. `io`：ABF 通道和 sweep、单位换算；文本格式读取。无法识别单位时明确报错。
3. `analysis`：配置、检测、阈值/波形/放电统计、缺失值与质量标记；完全不依赖 GUI。
4. `export`：全新目录事务式导出、原始文件哈希、参数与版本、CSV/PNG。失败时清理临时输出，不留下貌似完整的结果。
5. `gui`：文件选择、参数、波形、逐事件复核/剔除、sweep 批量测量；文件处理和计算在后台线程。
6. `cli`：同一内核的多文件批处理，可自动测试和重现分析。
7. `tests` / `scripts` / GitHub Actions：已知信号验证、格式读取、导出、无窗口桌面检查、Mac 打包。

## 验收证据

- 已知三角波：幅度约 100 mV，半峰宽约 1 ms，上/下降斜率约 ±100 mV/ms，AHP 相对基线 10 mV，均在采样误差容差内。
- 无放电、单次、多次和不同间隔：事件数、频率、ISI、适应比与缺失值符合定义。
- 错误单位、NaN、倒序、不规则采样、无效分析区间：拒绝处理而非静默纠正。
- 生成 ABF1 二进制后重新读取：验证比例和多 sweep；额外验证公开 ABF2 样本，但不把样本来源当作人工生理标注。
- 无窗口 Qt：加载演示、批量分析、剔除/恢复、参数变化失效、切换 sweep 与后台错误恢复。
- 导出保留参数、手动排除、数据哈希和有效样本数，不覆盖旧目录。

## 后续可扩展范围

有真实实验协议和代表性文件后，再考虑刺激电流解析、f–I 曲线、rheobase、输入电阻/膜时间常数、细胞与组级统计、项目保存、手动补加事件和更丰富的质量审核。第一版不先建立这些未确定的模块。
