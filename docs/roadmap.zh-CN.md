# 分析功能开发计划

[English](roadmap.md) | **简体中文**

更新日期：2026-11-02。继续以 Python 分析和结果交付为主，保留并暂停 Qt 开发。以下是按依赖排列的开发任务，不代表已实现、与 Clampfit 数值等效或承诺交付日期。

## 对照范围和证据

本次读取了 [Molecular Devices 官方 pCLAMP 11/11.4 产品说明](https://www.moleculardevices.com/products/axon-patch-clamp-system/acquisition-and-analysis-software/pclamp-software-suite)，对应章节为 NEW Minis Analysis Feature、Comprehensive analysis tools、Population spike analysis、Action potential analysis、Batch analysis 及批量过滤 FAQ。访问日期为 2026-11-02，[检索记录](clampfit-sources.json)保留地址和内容哈希。

官方说明明确区分 Clampfit 分析、Clampex 采集及 AxoScope 背景记录；AP 搜索、群体峰及批量宏标为 Advanced，Minis Search 标为 11.4 功能。该页面能支持功能缺口盘点，不能确定每个算法的计算定义。具体版本支持及数值等效仍需对应手册和实验导出结果确认。膜测试显示、采集协议编辑、连续采集及硬件数字输出不列入当前分析项目范围。

## 现有能力与缺口

- **动作电位：部分具备。** 已有数量、峰时刻/电压、固定 dV/dt 起始点、起始点至峰的幅度/半宽/上升时间、最大斜率、AHP、ISI 和简单适应指标。尚无 APD90、专门的复极/衰减测量；现有定义也尚未证明等于 Clampfit。
- **事件管理：部分具备。** API/保留的 Qt 支持剔除与恢复；本轮新增来源绑定的复核表及校验。尚无手动补加、双人裁决、可审计地应用标注。Minis 的重叠事件能力也尚未实现。
- **区域与图表：部分具备。** 已有一个主分析窗、一个基线窗和全部 sweep 分页波形。官方列出 24 对游标、I–V、直方图；项目尚缺命名多区域、I–V 和专门的分布图。优先开发可脚本调用的区域定义，无需复制游标界面。
- **批量工作流：部分具备。** 已有多文件/sweep 共用配置导出；尚缺保存和验证分析配方、按协议选择区域、逐文件失败记录/恢复、通用过滤宏。
- **突触事件/Minis：未实现。** 当前电压模型会拒绝 pA 电流通道。需建立独立的电流模型、事件动力学/电荷测量和重叠事件复核。
- **群体峰：未实现。** 面积、coastline、配对脉冲等需要场电位工作流，不能用细胞内 AP 半宽直接替代。
- **单通道：未实现。** 官方 FAQ 确认单通道记录的批量过滤。理想化、驻留时间和开放概率可作为专项候选，但在声称与厂商功能对齐前，需要额外核实手册及方法。

曲线拟合、FFT/功率谱、漏电扣除和更多滤波器列为**候选扩展**。本次读取的页面不足以核实其详细 Clampfit 范围，后续查对应手册；本计划不是所有 Clampfit 版本的完整目录。

## P0：建立可信复核和实验信息

**本轮完成：** `review-create` 从已有结果生成 sweep 表和可选的宽松检测独有候选表；`review-validate` 校验源文件哈希、身份字段、重复/缺失行、标签范围、标注人及依据，输出覆盖率。包含全部 sweep，避免只检查机器学习排在前面的记录。标签不会改动分析结果，见[使用流程](review-workflow.md)。

**继续开发：** 完整区间标注（包含主检测事件和所有检测器都漏掉的事件）、独立复核/分歧裁决、带理由和前后数量的纠正记录、可复用导出器中的候选片段、项目和分析配方保存。旧表缺少身份绑定，不静默迁移其判断。原结果保留，纠正后另生成带来源的新结果。

**实验信息前提：** 补齐动物/细胞/记录 ID、记录模式、刺激来源、电流单位和校准、协议区间及实验人员确认。已经可以解析启用 DAC 的 epoch，但未知单位的 DAC level 不能直接写作 pA；区分命令电流和实际测量电流。

**验收：** 源文件变化、通道/时间/配置错配、重复判断及过期表均能被发现；未知信息保持缺失；纠正可重放、可回退且不覆盖旧结果；检测准确性评估以完整人工复核区间为依据。

## P1：优先补全电流钳实验分析

1. **AP 波形扩展：** 核实参考电压、交点、截断和插值规则后增加明确命名的 APD90 类指标、10–90% 上升/衰减、相图、对齐波形、burst 与适应统计。保留旧 `ap-dvdt-1`，新数值方法单独命名。
2. **刺激响应：** 电流阶跃及单位确认后计算潜伏期、f–I、rheobase 和增益。区分“测试阶跃中最小引发放电的电流”和未直接观察到的精确阈值。单位/校准缺失时不输出依赖电流的结论。
3. **被动膜性质：** 使用合适亚阈值阶跃计算输入电阻、膜时间常数、sag 和有条件的电容估计；限定拟合窗，输出残差、拟合质量与模型假设，不跨 AP 拟合，不把失败的单指数拟合换算为电容。
4. **细胞/动物汇总：** 保留层级与重复测量，逐级报告有效数和缺失；统计推断需实验设计和独立生物学 ID。

**验收：** 可手算波形/指数响应、噪声/边界/失败案例、单位换算和协议错配测试；之后在设置一致的条件下，与盲法人工或 Clampfit 导出逐事件逐参数对照。容差依据采样率和研究用途预先确定。缺少电流或生物 ID 时仅阻止依赖它的分析。

## P2：通用信号处理和可复现批处理

增加命名多区域、显式基线校正、有边缘/瞬态规则的可选滤波、对齐/平均、带分箱设置的分布、I–V、分析配方、逐文件恢复及项目重开。明确研究问题和方法后再开发拟合/FFT/功率谱。原数组不修改，每步处理、单位和参数导出；不能默认先去噪再测形态。

**验收：** 保存配方可重放；拒绝不兼容单位/区间；记录逐文件失败；验证滤波频响/边缘、对齐偏移、平均有效数、直方图总数及已知 I–V 关系；量化滤波导致的阈值、半宽和斜率偏差。

## P3：电压钳和突触事件

增加有严格单位的电流模型，支持内向/外向事件、基线/噪声估计、阈值/模板候选、幅度、频率、上升/衰减、电荷、诱发潜伏期和配对脉冲。先建立重叠/伪迹复核，再考虑自动解卷积；连续记录需控制内存。

**验收：** 已知幅度/电荷/时间常数/重叠的合成电流，极性/单位/窗口/拟合失败，独立人工完整区间的误检次数每分钟和动力学偏差。需代表性电压钳数据和协议元数据；当前 AP 文件不能验证此模块。

## P4：专项功能与机器学习

在获得数据和方法依据后开发群体峰/场电位、单通道理想化和驻留时间等独立模块。硬件控制及界面功能对齐暂缓。

机器学习继续用于可关闭的复核辅助。当前 Isolation Forest 排序仍是探索性结果。先用完整人工标签，在相同复核预算下比较随机抽查、规则提示和 ML 排序，记录漏检/误检、复核时间及独立来源层级的不确定性。有实测收益后再考虑轻量监督分类；按最高独立来源划分训练/验证/冻结测试集，预处理也只在训练集拟合。生物 ID 未知、候选未标注的现状不能支持监督训练、准确率宣称或细胞类型/因果诊断。去噪模型必须先验证形态偏差，不隐含上传数据或发布模型的授权。

## 执行顺序

先完成 P0 复核及元数据证据 → P1 当前 AP 分析 → 按需要提取 P2 通用组件 → 有适用数据后推进 P3 → P4 专项。每次交付同步中英文 README、方法元数据、测试及计划状态；仅在用户明确要求时恢复 GUI 开发。
